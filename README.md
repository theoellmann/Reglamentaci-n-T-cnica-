# Reglamentación Técnica

Para Caro C.

Propuesta de supresión de la Dirección Nacional de Reglamentos Técnicos (DNRT): derogar los reglamentos técnicos que no superan un análisis costo-beneficio, delegar los que protegen riesgos reales a organismos sectoriales con capacidad de fiscalización, y reasignar las funciones residuales OMC/Mercosur.

Todas las citas normativas y académicas fueron verificadas contra fuente primaria.
